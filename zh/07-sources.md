# 事实溯源：每条结论的证据强度

> 这一份的用途只有一个：**让读者知道哪些话是跑出来的，哪些话是我想出来的，以及跑出来的那些量化到哪一步。**
> 白皮书最贵的不是结论错，是**读者无法区分**这几类。

---

## 1. 两维定义

**为什么不再用单档「强度」**：它会逼着人在"实测"和"主张"之间二选一，而真实情况大量落在中间 ——
机制**已经连续运行很久、有完整账本**，但**没有做过"不带它会怎样"的对照**。
把它标成"实测"是夸大，标成"主张"是抹杀。所以拆成两维。

### 维度一 · 运行状态

| 档 | 定义 |
|---|---|
| **全面运行** | 有历史产物，且最近 7 天仍在持续产生 |
| **部分运行** | 有产物但覆盖不全（含人工步骤 / 只覆盖部分入口） |
| **仅约定** | 只有文档或提示词里的纪律，无强制校验、无产物 |
| **尚未实现** | 纯设计 |

### 维度二 · 证据强度（按量化程度排）

| 档 | 定义 | 反例（不算这一档） |
|---|---|---|
| **Q0 受控量化** | 有对照 / 消融 / 可对比基线，能给出数字差 | "我换过，感觉好多了" |
| **Q1 可追溯未量化** | 有运行产物与账本，可复算、可回溯，**但没有对照** | "一直在跑" 但拿不出记录 |
| **Q2 事件观察未量化** | 有具体事件支撑，未系统留痕 | "应该会这样" |
| **Q3 设计推理** | 无运行证据，仅设计论证 | 任何"一般都会"的表述 |

**写作纪律**：正文默认 `Q1` 或以上；凡 `Q3` 条目，正文对应段落必须自带提示（本稿执行域已加卷首警示）。

> **核心立场（写在这里，因为它是整份文档的前提）：**
> 这套架构是**实际堆出来的** —— 每条不变量的来源都是真实运行与真实事故，不是推演。
> 缺的是**量化**（"不带它会差多少"），不是**证据**（"它到底做没做"）。
> 把这两者混为一谈，会让读者把"没算过差多少"误读成"没做过"。

## 4. 已知边界：我们知道自己卡在哪

这一节是本稿最想请审阅者看的部分：**不是"还没有问题"，而是"问题已被定位"**。

### 4.1 三条弱点（持续有效）

1. **盲审员同源** —— 审计方与被审方都是 LLM，**语义级"记岔"拦不住**。独立性解决的是"立场辩护"，不是"同源盲区"。
2. **审计文本非行为** —— 只审"说了什么"，看不见副作用（注册表 / 文件系统写入类）。
3. **体系自身是故障源** —— 审计链、注入链、闸门链本身也会坏（元问题）。

### 4.2 由此得到的定位调整

> **冻结架构，不再加码**；定位从「防错」调整为「**稳定运行 + 低频查证**」。
> 唯一值得补的能力 = **行为层审计**（敏感写入后主动回查），见 §3。

这条判断是**主动收缩**，不是能力不足的托词：再加机制只会让第 3 条弱点（体系自身是故障源）变严重。

## 5. 为什么一条 Q0 都没有，以及怎么办

做受控实验需要"不带它跑一遍"，而本系统有两类条目**不允许做这种实验**：

| 条目类型 | 为什么不能做对照 |
|---|---|
| 破坏性顺序类（如 `INV-M4` 沉淀先于清空） | 反序实验 = **真丢数据** |
| 安全边界类（如 `INV-E3` 前置分类） | 对照实验 = **先造一个坏分类器** |

所以本稿的策略不是"补造实验"，而是：**把每条的证据到哪一层写清楚**，并把**能做的实验**列进 §6 交给愿意做的人 —— 读者在自己的环境里做对照，比本机做更安全。

## 6. 三个可做的实验（把 Q2/Q3 推向 Q0 或 Q1）

### 实验一：审计一致性（`INV-E1` / `E2` 的量化）

- **做法**：取 20 个真实片段，做三组判定：① 同上下文自审 ② 外部独立 + 原始片段 ③ 外部独立 + 摘要输入。
- **指标**：三组"发现问题数"与"人工复核为真的比例"；同组重跑两次的分类一致率。
- **预期**（Q3）：① 发现问题数最少；③ 明显少于 ②；重复一致性 ② > ③。
- **判据**：若 ② 与 ① 无显著差异，则 `INV-E1` 被证伪，**整条重写**。

### 实验二：闸门收益与误判不对称（`INV-D4` 的量化）

- **做法**：回放一天的信号流（正常 + 注入 1 个真实失败），统计闸门三态分布与模型调用次数。
- **指标**：正常日模型调用数（应 = 0）、注入失败被唤醒的延迟、误唤醒数。
- **预期**：调用数 0；注入失败在窗口内唤醒；误唤醒数 > 0 但代价可接受。

### 实验三：盲审去标记的 A/B（`INV-M8` 的量化）

- **做法**：同一批条目，一组带旧置信度标记给盲审、一组不带，比较评分分布与"新条目上位率"。
- **指标**：分布差异显著性；两周内新条目进入题库的比例。
- **预期**：带标记组的高分条目复现率更高（光环效应）。
