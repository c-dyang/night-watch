# 事实溯源：每条结论的证据强度

> 这一份的用途只有一个：**让读者知道哪些话是实测的，哪些话是我想出来的。**
> 白皮书最贵的不是结论错，是**读者无法区分**这两类。

---

## 1. 三档证据定义

| 档 | 定义 | 反例（不算这一档） |
|---|---|---|
| **实测** | 在本实现里跑过、产物可查、可重跑 | "我记得是这样" / "一般都会这样" |
| **观察** | 出现过一次明确现象，但未做对照实验 | 多次重复即升级为实测，但需要留痕 |
| **主张** | 设计推理，尚未验证 | 任何"应该可行"的表述 |

**写作纪律**：正文不标 `[主张]` 就默认是实测或观察；凡本表列为主张的，正文对应段落必须自带提示（本稿执行域已加卷首警示）。

## 4. 三个可做的实验（把主张变成实测）

如果我要把这份白皮书从 `v0.1-draft` 推到 `v1.0`，需要按顺序做这三件事。读者也可以自己做。

### 实验一：判定一致性（验证 INV-E1 / E2）

- **做法**：取 20 个真实片段，做三组判定：① 同上下文自审 ② 外部独立 + 原始片段 ③ 外部独立 + 摘要输入。
- **指标**：三组"发现问题数"与"人工复核为真的比例"；同组重跑两次的 `class` 一致率。
- **预期**（主张）：① 发现问题数最少；③ 明显少于 ②；重复一致性 ② > ③。
- **判据**：若 ② 与 ① 无显著差异，则 INV-E1 被证伪，**必须整条重写**，不许改措辞。

### 实验二：预检收益与代价（验证 INV-E5 / E6）

- **做法**：同一批任务跑两遍，一遍开预检一遍关，记录越权/遗漏事件数与总耗时。
- **指标**：事故率变化、平均耗时变化、被预检拦下（而非提示）的次数（应≈0）。
- **预期**：事故率下降、耗时上升但可接受、阻断次数为 0。

### 实验三：闸门零成本与误判不对称（验证 INV-D4 / D5）

- **做法**：回放一天的信号流（正常 + 注入 1 个真实失败），统计闸门三态分布与模型调用次数。
- **指标**：正常日模型调用数（应 = 0）、注入失败被唤醒的延迟、误唤醒数。
- **预期**：调用数 0；注入失败在窗口内唤醒；误唤醒数 > 0 但代价可接受。
