Night-watch

起点只有两条硬性要求：无限任务范围（任务领域不预先封闭）与·单会话入口（对用户只有一个对话框）。两者叠加在无人值守的机器上，压出了防偏 · 防忘 · 防崩三条线，再长出三域架构 —— 不是先有蓝图，是实际堆出来的。

It starts from two hard requirements: unbounded task scope (the task domain is never closed in advance) and ·a single entry (the user sees exactly one conversation). Stacked on an unattended machine, they press out three guards — drift, forgetting and silence — which in turn grow the three domains. Not a blueprint first: built up from real operation.

会话可以每天清空，因为记忆不在会话里；模型可以很便宜，因为难的部分都被搬进了结构；而"信不信"这件事，单独用一个模块来管。
Sessions can be wiped every day, because memory is not in the session; models can be cheap, because the hard parts were moved into structure; and "should I believe this" is managed by a module of its own.

三域咬合 memory / execution / device

Three domains memory / execution / device

三域不共享任何运行时 —— 没有共享内存、没有 RPC、没有消息队列。它们只共享文件格式，因此任一域都能整体替换。

The three domains share no runtime — no shared memory, no RPC, no queue. They share file formats only, which is what makes each of them replaceable wholesale.
